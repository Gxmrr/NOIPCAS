## Overview

NOIR is an educational casino simulator built with React Native. It explores interface design, randomized game outcomes and session analytics using virtual credits with no monetary value.

## Features

- Roulette, slots, blackjack and dice simulations
- Session history and balance analytics
- Configurable session limits and probability information
- Customizable appearance and accessibility settings
- English and Russian localization
- Local data persistence

## Getting started

```bash
git clone https://github.com/Gxmrr/NOIPCAS.git
cd NOIPCAS
npm install
npx expo start
```

Press `w` for web, `a` for Android or `i` for the iOS simulator on macOS.

## Built with

React Native · Expo · JavaScript · AsyncStorage

## Note

This is a non-monetary educational simulation. No deposits, withdrawals, real-money wagering or bank integrations are supported. The Expo project configuration has been reconstructed; device builds have not been verified.
